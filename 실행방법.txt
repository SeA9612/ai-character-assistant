AI 캐릭터 비서 v0.2.0 실행 방법
==============================

이 파일은 메모장으로 읽을 수 있는 설치/사용 안내입니다.
배포본에는 제작자의 GPT 로그인이나 개인정보가 들어 있지 않습니다.
프로그램을 내려받은 사용자가 본인 계정으로 로그인해야 합니다.
완성된 설치형 EXE가 아니라 소스 기반 공개 테스트 버전입니다.

1. 준비할 프로그램
-----------------
Windows 10/11, Node.js 22 이상, Python 3.10 이상과 pip,
pnpm 11, app-server와 dynamicTools를 지원하는 공식 OpenAI Codex CLI,
PC 작업용 PowerShell 7 (pwsh.exe)이 필요합니다.

Node.js: https://nodejs.org/
Python: https://www.python.org/downloads/
Codex 안내: https://learn.chatgpt.com/docs/auth
PowerShell 7: https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows

Node.js와 Python 설치 후 새 PowerShell에서 다음 명령을 실행합니다.

    npm install --global pnpm@11
    npm install --global @openai/codex

설치 가능한 Codex 버전, 모델, 구독 권한은 사용 시점의 공식 안내를 확인하세요.

2. 압축 해제와 최초 설치
----------------------
릴리즈 Assets에서 ai-character-assistant-v0.2.0.zip을 내려받으세요.
GitHub가 자동 생성하는 Source code ZIP과 구분하세요.
ZIP을 완전히 풀고 프로젝트 폴더에서 PowerShell 7을 엽니다.
아래 명령은 서버/화면 의존성, Electron, 음성용 Python 3.12 환경을 준비합니다.
처음에는 인터넷 연결과 다운로드 공간이 필요합니다.

    .\setup.ps1

음성 설치를 나중에 하려면 .\setup.ps1 -SkipSpeech 를 사용합니다.
음성만 다시 설치하려면 .\setup-speech.ps1 을 사용합니다.

PowerShell이 스크립트 실행을 차단하면 조직/PC의 실행 정책을 확인하세요.
정책을 우회하는 명령은 제공하지 않습니다.
실행이 허용된 환경에서 진행하거나 아래 수동 명령을 사용하세요.

    pnpm install --frozen-lockfile --ignore-scripts --node-linker=hoisted
    cd frontend
    pnpm install --frozen-lockfile --ignore-scripts --node-linker=hoisted
    node node_modules/electron/install.js
    pnpm run build
    pnpm run build:web
    cd ..

음성 환경 설치는 setup-speech.ps1의 명령을 참고하세요.

3. 서버 실행과 본인 GPT 연결
--------------------------
프로젝트 폴더에서 실행합니다.

    .\start.ps1

또는 Node.js가 PATH에 등록돼 있다면 다음 명령으로 서버를 켤 수 있습니다.

    node server/main.mjs

브라우저에서 다음 주소를 엽니다.

    http://127.0.0.1:12393

ChatGPT로 로그인 버튼을 누른 뒤, 나타난 로그인 페이지 열기를 선택합니다.
공식 OpenAI 로그인 화면에서 본인 계정으로 인증합니다.
프로그램으로 돌아와 상태 확인을 누르고, 캐릭터와 대화하기를 선택합니다.

이 앱은 .runtime/codex 를 전용 로그인 저장소로 사용합니다.
PC에 이미 로그인한 다른 Codex 앱의 계정은 자동으로 가져오지 않습니다.
ChatGPT 구독 사용량/접근 권한이 필요하며 API 키 인증은 거부합니다.
기존 ChatGPT 대화와 메모리는 자동으로 이어지지 않습니다.

로그인 정보는 비밀번호처럼 취급하세요.
실행 후 생성된 .runtime 폴더나 auth.json을 다른 사람에게 보내면 안 됩니다.

4. 데스크톱 앱과 펫 모드
----------------------
서버를 켜둔 상태에서 별도 PowerShell로 실행합니다.

    .\start-desktop.ps1

왼쪽 위 모드 메뉴에서 Pet Mode를 고르면 투명 펫 모드가 됩니다.
트레이 메뉴의 Window Mode로 돌아오고 Exit로 종료할 수 있습니다.
서버는 서버 콘솔에서 Ctrl+C로 종료합니다.

5. 음성 대화
-----------
실행 시 마이크가 기본으로 켜집니다. 권한이 필요하면 직접 허용해주세요.
마이크 버튼으로 끌 수 있고, 끄면 해당 실행 중에는 꺼진 상태를 유지합니다.
기본 설정에서는 한 번 말한 뒤에도 계속 듣습니다.
AI가 답변을 만들거나 읽는 중에는 자기 음성을 새 명령으로 받지 않습니다.
음성 답변 켜짐/꺼짐 버튼으로 답변 읽기를 바꿀 수 있습니다.
처음 인식할 때 Whisper 모델을 내려받아 시간이 걸릴 수 있습니다.

인식은 로컬 Faster-Whisper, 합성은 Edge 온라인 음성 서비스입니다.
음성 합성에는 답변 텍스트가 외부 서비스로 전달됩니다.
마이크/스피커 장치 권한과 Windows 입력/출력 장치를 확인하세요.

6. 화면 인식과 PC 작업
-----------
Screen 탭에서 화면 공유를 시작하고, 공유할 창을 직접 고릅니다.
미리보기를 확인한 후 화면에 관해 질문하세요.
질문이나 먼저 말하기가 실행될 때 해당 창의 이미지가 GPT에 전달됩니다.
전체 동영상을 계속 분석하는 기능은 아닙니다.
미리보기를 다시 누르면 공유를 멈춥니다.
화면·PC 작업 켜짐 상태에서는 AI가 요청 처리에 필요한 창의 화면과 컨트롤을
직접 확인할 수 있습니다. 파일 작업, 앱 실행, 창 전환, 클릭, 입력을 요청할 수 있습니다.
명령과 입력 조작은 승인 카드의 내용을 읽고 이 작업 실행을 눌러야 진행됩니다.
취소하면 해당 요청에서 추가 도구 실행도 차단됩니다.
PC 작업 중지 또는 손 버튼은 현재 작업을 중단하며 완료한 변경을 되돌리지는 않습니다.
현재 Windows 사용자 권한으로 실행하고 관리자 권한을 자동 취득하지 않습니다.
펫 모드에서 승인이 필요하면 창 모드로 돌아옵니다.
화면·컨트롤·명령 결과가 로그인한 AI 서비스로 전송될 수 있습니다.
가려진 창, 관리자 권한 앱, 잠금 화면, 보호된 입력창에는 제한이 있습니다.
예: 현재 작업 폴더에 할 일 메모를 만들어줘.

7. 먼저 말하기
-------------
먼저 말하기 시작을 누르고 대기 초를 설정합니다.
기본값은 꺼짐/60초입니다. 테스트 최솟값은 5초입니다.
먼저 말하기 중지를 누르면 끌 수 있습니다.
먼저 말하기는 PC 도구를 사용하지 않고 대화만 합니다.
구독 사용량을 소비하므로 테스트 후에는 꺼두는 것이 좋습니다.

8. 문제 해결
-----------
연결 안 됨: 서버 콘솔을 확인하고 화면의 재연결을 누릅니다.
포트 사용 중: 이 프로그램 서버가 이미 켜져 있는지 확인합니다.
Codex 없음: codex --version과 codex app-server --help를 확인합니다.
경로 지정 필요: $env:CODEX_BINARY = '본인 PC의 codex.exe 전체 경로'
음성 엔진 없음: setup-speech.ps1을 다시 실행합니다.
PC 작업 실패: PowerShell 7 설치와 pwsh --version을 확인합니다.
다른 경로에 설치했다면 서버 실행 전 ASSISTANT_POWERSHELL 환경변수에 실행 파일 경로를 지정합니다.
PC 작업 승인 카드가 나타나면 실제 명령을 확인하고 실행 또는 취소를 선택합니다.
모델/음성 다운로드 실패: 네트워크 정책과 서비스 접속 상태를 확인합니다.

9. 테스트와 제한
---------------
개인 계정 없이 자동 테스트를 실행할 수 있습니다.

    node --test tests/assistant.test.mjs tests/pc.test.mjs

14개 테스트와 웹/Electron 빌드를 확인한 공개 테스트 버전입니다.
실제 구독 AI의 파일 생성/다시 읽기와 캐릭터 앱 화면 상태 인식을 확인했습니다.
텍스트/인식된 음성의 PC 작업 경로와 승인/거절을 자동 검사했습니다.
실제 음성 왕복, 가상 마이크 경로, 화면 인식, 자동 발화, 펫 표시를 검증했습니다.
물리 장치 음질, 다중 모니터 드래그, 카메라, 장시간 사용은 추가 확인이 필요합니다.
다양한 외부 앱의 클릭/문자 입력은 추가 검증 대상입니다.
원본 SDK의 엄격한 전체 TypeScript 검사 오류는 남아 있습니다.
