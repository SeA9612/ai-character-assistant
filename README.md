# AI 캐릭터 비서

Open-LLM-VTuber의 캐릭터 화면을 바탕으로 만든 Windows용 개인 AI 비서입니다.
본인의 ChatGPT 구독으로 로그인하고, 텍스트·한국어 음성 요청에 따라 화면 확인과 PC 작업을 수행합니다.

**현재 버전은 v0.2.1 소스 기반 공개 테스트 버전입니다.** 제작자의 로그인 정보나 대화 기록은 들어 있지 않습니다.
처음 실행할 때 사용자가 직접 로그인해야 합니다. 다른 구독형 AI 제공자는 아직 지원하지 않습니다.

## 기능

- **v0.2.1 수정:** 펫·트레이 전환, 입력 포커스와 클릭 오류 수정. 현재 모니터 안의 작은 펫 창에서 주요 기능을 직접 제어합니다.
- **v0.2.0 추가:** AI가 필요한 창의 화면과 컨트롤을 확인하고 파일·앱 작업 수행
- Windows 창 전환, 클릭, 문자 입력, 단축키, 스크롤, PowerShell 작업
- 실행할 명령·입력 조작을 검토하는 승인 카드, 취소와 PC 작업 중지
- 마이크 기본 켜짐, 수동 끄기, 발화 후 계속 듣기, AI 음성 재입력 방지
- 한국어 마이크 입력 → 로컬 Faster-Whisper 인식 → ChatGPT 구독 AI 응답
- Edge TTS 한국어 음성 출력, Live2D 표정·입 움직임, 응답 중단
- 선택한 창의 화면을 이미지로 전달해 질문하기
- 대기 후 먼저 말하기: 기본 꺼짐, 대기 시간 설정 가능
- Electron 데스크톱 펫 모드와 창 모드
- 로컬 대화 기록 저장·불러오기
- 마크다운 강조 기호를 자막과 음성에서 정리

## 설치와 실행

릴리즈 Assets의 `ai-character-assistant-v0.2.1.zip`을 내려받아 압축을 푸세요.
전체 소스가 이 ZIP 안에 있습니다. 저장소의 문서·ZIP을 묶은 GitHub 자동 생성 Source code ZIP과 구분하세요.
자세한 순서는 [실행방법.txt](실행방법.txt)를 메모장으로 열어 확인하세요. 별도 릴리즈 첨부 파일명은 `RUN_GUIDE_KO.txt`입니다.

필요한 프로그램은 Node.js 22 이상, pnpm 11, Python 3.10 이상(음성 환경 설치용),
`app-server`와 실험적 dynamicTools를 지원하는 공식 Codex CLI, PC 작업용 **PowerShell 7 (`pwsh.exe`)**입니다.
음성 실행 환경은 프로젝트 내부에 Python 3.12로 따로 만듭니다.
GitHub ZIP을 받은 경우 먼저 압축을 풀고 해당 폴더에서 PowerShell을 여세요.

```powershell
npm install --global pnpm@11
npm install --global @openai/codex
.\setup.ps1
.\start.ps1
```

브라우저에서 `http://127.0.0.1:12393`을 열고 **ChatGPT로 로그인**을 선택합니다.
이 앱은 전용 `.runtime/codex` 폴더를 사용하므로 기존 Codex 로그인과 분리됩니다.
인증이 끝나면 **상태 확인 → 캐릭터와 대화하기** 순서로 진행하세요.
구독 권한과 사용량 제한은 본인 계정에 적용됩니다. API 키 인증은 사용하지 않습니다.

데스크톱 앱은 서버를 켜둔 상태에서 별도 PowerShell로 실행합니다.

```powershell
.\start-desktop.ps1
```

모드 메뉴의 **Pet Mode**로 전환합니다. 펫 창의 **창 모드** 버튼, 트레이의 **Window Mode** 또는 트레이 아이콘 두 번 누르기로 돌아올 수 있습니다.
X로 창을 닫으면 트레이에 숨겨지며, 숨긴 상태에서도 트레이 모드를 선택하면 다시 표시합니다. 완전히 끝내려면 트레이의 **Exit**를 사용하세요.
펫은 현재 모니터 안에 최대 480×760 크기로 표시하며 위쪽 제목 영역을 드래그해 옮깁니다.
펫 모드에도 마이크·음성 답변·PC 작업·중지·먼저 말하기·화면 공유 버튼이 있습니다.
완성된 설치형 EXE를 제공하는 릴리즈는 아닙니다. 최초 설치에는 인터넷 연결과 다운로드 공간이 필요합니다.

## 개인정보와 저장 위치

- 로그인·설정·캐시: `.runtime/` 내부. Git 업로드와 배포 ZIP에서 제외합니다.
- 대화 기록: `.runtime/history/`. 로컬에 저장합니다.
- 마이크 음성 인식: 로컬 실행. 처음에는 Whisper 모델을 다운로드합니다.
- AI 답변 생성: 로그인한 사용자의 ChatGPT 서비스로 질문과 대화 문맥을 전송합니다.
- 음성 합성: 답변 텍스트를 Edge 온라인 음성 서비스에 전송합니다.
- 화면·PC 작업이 켜져 있으면 요청을 처리하기 위해 AI가 필요한 창의 화면·컨트롤·명령 결과를 확인해 ChatGPT로 전송합니다. 지속 녹화하지 않습니다.
- Screen으로 직접 공유한 창의 이미지는 질문이나 먼저 말하기 시에도 전달할 수 있습니다.
- 기존 ChatGPT 대화와 메모리를 자동으로 가져오지는 않습니다.

공유를 멈추려면 Screen 미리보기를 다시 누르세요. 먼저 말하기는 테스트 후 직접 끌 수 있습니다.
자세한 배포 제외 항목은 [PRIVACY.md](PRIVACY.md)에 정리했습니다.

## PC 작업 사용법

`화면·PC 작업 켜짐`을 확인하고 `현재 작업 폴더에 할 일 메모를 만들어줘`처럼 요청하세요.
승인 카드에서 실제 명령·입력 내용을 읽은 뒤 **이 작업 실행**을 누릅니다. **취소**하면 해당 요청에서 추가 도구 실행도 차단합니다.
**PC 작업 중지**는 현재 작업을 중단하며 이미 완료한 변경을 되돌리지는 않습니다.
현재 Windows 사용자 권한으로 실행하고 관리자 권한을 자동 취득하지 않습니다.
먼저 말하기는 PC 도구 없이 대화만 합니다. 펫 모드에서 승인 요청이 오면 창 모드로 돌아옵니다.
자세한 동작과 제한은 소스 ZIP의 `docs/PC_ASSISTANT.md`에 있습니다.

## 테스트와 현재 제한

자동 테스트 16개와 웹/Electron 빌드를 통과했습니다. 숨김/최소화 후 복구와 모니터 배치 검사도 포함합니다.
실제 Electron 앱에서 닫기→숨김→트레이와 동일한 모드 선택 경로로 펫/창 복구를 3회 반복했습니다.
펫 입력창의 실제 키보드 입력·AI 응답, TTS 재생, 공유 창 인식, 먼저 말하기, 가상 마이크→VAD→음성 인식→AI 응답, PC 승인 화면 전환·취소도 확인했습니다.
실제 구독 AI의 테스트 파일 생성·다시 읽기와 앱 화면 상태 인식은 v0.2.0에서 확인했습니다.
텍스트·인식된 음성의 PC 작업 경로, 승인·거절, 대화 전용·먼저 말하기의 도구 차단도 검사했습니다.
v0.1.0에서 한국어 합성·인식·구독 AI 음성 왕복,
가상 마이크 입력/VAD/재생, 실제 선택 창의 화면 인식, 5초 자동 발화, 투명 펫 표시를 확인했습니다.

물리 마이크·스피커의 품질, 여러 모니터를 가로지르는 드래그, 카메라 입력,
장시간 실행과 설치형 패키지는 추가 확인이 필요합니다. 다양한 외부 앱의 클릭·입력 작업은 추가 검증 대상이며, 가려진 창·관리자 권한 앱·잠금 화면·보호된 입력창은 제약이 있습니다.
원본 Live2D SDK의 엄격한 전체 TypeScript 검사 오류는 남아 있으며 Vite 실행 빌드는 통과합니다.

```powershell
node --test tests/assistant.test.mjs tests/pc.test.mjs tests/pet-mode.test.mjs
```

위 자동 테스트는 실제 계정 로그인이나 AI 호출이 필요하지 않습니다.
